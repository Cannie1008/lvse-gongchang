# 悠米一下-绿色工厂项目申报

> 按 14 项指标给企业算分，告诉你差几分、先做什么、什么时候报。

## 这是什么

一个用于**绿色工厂（市级、省级、国家级）研判与申报**的辅助技能。

绿色工厂的评价规则是公开的，但企业真正卡住的从来不是"规则是什么"，而是三件事：
**我的数算得对不对、我够不够线、我该先干哪一件。**

这个技能把这三件事变成可以算的东西：

- 按 GB/T 36132—2025 的 14 项指标算分，缺数据的标"待定"，不替你估
- 告诉你确定分、待定分、上限，以及和目标分数线的差距
- 排出**最快过线路径**，每一步写清加几分、要做什么、受不受评价年限制
- 把缺口换算成具体的量：约 512 张绿证、再补 2 项能碳系统功能、取水再减 2.16 万 m³
- 倒排申报时间，算出评价年还剩多少天可以改善数据
- 直接出两份 Word：**研判报告**（给负责人决策）、**自评价报告底稿**（给经办人改写）

## 适合谁

- 想报市级/省级/国家级绿色工厂，但不知道自己在哪个位置的制造企业
- 已经报了，被退回或拿不准分数，想复核口径的
- 已是国家级，每年要做动态管理表的
- 帮企业做申报辅导的咨询机构（报告可写自己的出具单位）

## 怎么用

装好后直接说人话就行，不用记命令：

> 我们江苏的，齿轮厂，现在市级，想报省级。年用电 1890 万度，光伏自用 260 万度，天然气 38 万方，产值 6.2 亿，取水 9.6 万吨……能不能报？

它会自己判断要不要调用、要不要跑脚本。手上有整表数据的，直接发过来就行。

## 边界（重要）

- **不编数据。** 没有可靠来源的对标值一律标"待定"，并告诉你该去哪找，不会替你估一个数凑分。
- **不把不该算的算进去。** 外购电当绿电、同一电量既算绿电交易又算绿证、往年投资挪进近三年、外购固废算进利用量——遇到这类要求会拒绝，并给合规的替代办法。
- **不承诺结果。** 只给"按规则推算是这样"，不说"一定能过"。
- **不代替企业注册、提交、签字盖章。** 生成的报告标了"AI辅助生成"，须人工核对；自评价底稿要法定代表人签字、单位盖章才完整。

## 数据安全

对话里的企业数据可能离开本机。在意保密时，先用 `绿色工厂离线打分器.html` 在本机算，只把导出的 JSON 或结论发过来。

## 关于 Excel 采集表

SkillHub 不接受 xlsx，市场版包里没有 `绿色工厂数据采集表.xlsx`。不影响算分：

- 用 `绿色工厂离线打分器.html` 在本机填，导出 JSON 发过来，效果一样
- 或者直接把数据用文字发过来，引擎照样算
- 需要 Excel 版（158 个公式自动算分，适合内部走流程）的，从本仓库或 Release 附件取

## 已知局限

1. 定性三项（工艺设备先进性、绿色设计、产品碳足迹）的三档计分是经验估计，平台细则以填报说明为准。
2. 非重点行业的对标值需要用户提供，工具不内置"行业平均"。
3. 重点行业要用平台上的行业指标表（`custom_model`），采集表和离线网页只支持通则 14 项。
4. 时间窗口按近两年规律推算，以当年通知为准。
5. 零碳工厂只核对"已是国家绿色工厂"和"年综合能耗≥1000 tce"两条，三项核心指标口径以 334 号附件 1 为准，本工具不代算。

## 更新

政策核对至 **2026 年 10 月 23 日**。每年需要更新：当年通知与分数线（`references/policy.md`）、重点行业名单、电力排放因子、缺省分数线、政策核对日期。改完用演示数据跑一遍，确认引擎、采集表、离线网页三处结果一致。
